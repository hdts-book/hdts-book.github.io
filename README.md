# hdts-book.github.io
# High-Dimensional Time Series

This repository provides the replication code and datasets for the book **High-Dimensional Time Series** [cite: 1].

## Authors
* Changryong Baek [cite: 1]
* Marie Düker [cite: 1]
* Vladas Pipiras [cite: 1]

**Publication Date**: September 1, 2026 [cite: 1]

## Repository Structure

The repository is organized according to the chapters and topics covered in the book [cite: 1]. 

* **`Chapter1/`**: Replication code for Chapter 1, which covers sparse vector autoregressive models [cite: 1].
* **`Chapter2/`**: Replication code for Chapter 2, which covers dynamic factor models [cite: 1].
* **`data/`**: Common datasets utilized across different chapters.

## Methodological Reference

The numerical methods and algorithms implemented in this repository correspond to the techniques detailed in the book's appendices [cite: 1]:
* Matrix operations (Appendix A) [cite: 1]
* Numerical optimization methods, including coordinate descent, ADMM, and FISTA algorithms for sparse VAR models (Appendix B) [cite: 1]
* Concentration inequalities (Appendix C) [cite: 1]
